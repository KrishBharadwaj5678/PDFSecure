<h1 align="center">🔐 PDF Secure</h1>

<p align="center">
   O PDF Secure facilita a criptografia, proteção e descriptografia de documentos PDF com uma poderosa proteção por senha.
</p>

![PDFSecureDemo](https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/demos/PDFSecure.png)

<img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso                             | Descrição                                                 |
| ----------------------------------- | --------------------------------------------------------- |
| 🔒 Criptografar PDFs                | Proteja seus PDFs com criptografia segura por senha       |
| 🔓 Descriptografar PDFs             | Remova facilmente a proteção por senha de PDFs protegidos |
| 📂 Gerenciamento seguro de arquivos | Garante que seus arquivos sejam gerenciados com segurança |
| 🚀 Rápido e leve                    | Dependências mínimas e desempenho otimizado               |
| 🧩 Suporte multiplataforma          | Funciona perfeitamente no Windows, macOS e Linux          |

## <img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros passos

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/PDFSecure.git
```

### 2️⃣ Navegar até o projeto

```bash
cd PDFSecure
```

### 3️⃣ Instalar as dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar a aplicação

```bash
streamlit run app.py
```
