<h1 align="center">🔐 PDF Secure</h1>

<p align="center">
   PDF Secure позволяет легко шифровать, защищать и расшифровывать PDF-документы с помощью надёжной парольной защиты.
</p>

## <img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность                    | Описание                                                   |
| ------------------------------ | ---------------------------------------------------------- |
| 🔒 Шифрование PDF              | Защищайте PDF-файлы с помощью надёжного шифрования паролем |
| 🔓 Расшифровка PDF             | Легко удаляйте парольную защиту с защищённых PDF-файлов    |
| 📂 Безопасная работа с файлами | Обеспечивает безопасное управление вашими файлами          |
| 🚀 Быстрота и лёгкость         | Минимум зависимостей и оптимизированная производительность |
| 🧩 Кроссплатформенность        | Работает на Windows, macOS и Linux                         |

## <img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/PDFSecure.git
```

### 2️⃣ Переход в директорию проекта

```bash
cd PDFSecure
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
