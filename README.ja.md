<h1 align="center">🔐 PDF Secure</h1>

<p align="center">
   PDF Secure は、強力なパスワード保護を使用して、PDF ドキュメントの暗号化・保護・復号化を簡単に行えるツールです。
</p>

![PDFSecureDemo](https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/demos/PDFSecure.png)

<img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能             | 説明                            |
| -------------- | ----------------------------- |
| 🔒 PDF の暗号化    | 強力なパスワード暗号化で PDF を保護できます      |
| 🔓 PDF の復号化    | 保護された PDF からパスワード保護を簡単に解除できます |
| 📂 安全なファイル処理   | ファイルを安全に管理できます                |
| 🚀 高速・軽量       | 最小限の依存関係で、パフォーマンスを最適化         |
| 🧩 クロスプラットフォーム | Windows、macOS、Linux でシームレスに動作 |

## <img src="https://github.com/KrishBharadwaj5678/PDFSecure/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/PDFSecure.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd PDFSecure
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを起動

```bash
streamlit run app.py
```
